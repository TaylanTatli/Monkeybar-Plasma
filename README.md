# MonkeyBar

This is a **Monkeytype** plasmoid for **KDE Plasma 6**, based on the [AROICE-HQ/monkeybar](https://github.com/AROICE-HQ/monkeybar).

Built with a vibe-coded approach, this plugin aims to provide quick access and a clean bar experience on the Plasma desktop.

## Purpose

This project was created to bring the MonkeyBar experience to the Plasma 6 ecosystem.

## Source

- Original project: https://github.com/AROICE-HQ/monkeybar

## Note

This project is prepared to be used as a plasmoid adapted for Plasma 6.
